NERIST
Jan 2022 – May 2026 · Arunachal Pradesh
GA4 GTM BigQuery Looker Studio SQL Consent Mode v2

Data & Analytics Intern — Full GA4 Implementation & Dashboard Build

What I Did

Designed and owned the GA4 measurement plan for the institutional web property — defined page taxonomy, event taxonomy, and custom dimensions to track user journeys across research and administrative sections. Conducted a full GTM audit identifying 46 issues (14 duplicate events, 11 broken tags, 9 events missing parameters, 3 Consent Mode gaps); rebuilt the container from scratch, raising average parameter coverage from ~15% to ~98%. Configured custom triggers, dataLayer push events, and variable mappings; debugged broken events end-to-end using GTM Preview and GA4 DebugView — including React SPA history-change tracking for virtual page_view. Wrote SQL against the GA4 BigQuery export for ad-hoc analyses on session quality, content engagement, and drop-off. Built Looker Studio dashboards consumed weekly by faculty and operations leads, with embedded 'so-what' commentary on each page. Implemented Consent Mode v2 defaults via GTM, reducing modelled data gaps from ~35% to ~8% of sessions.

Outcome

Institution gained its first fully auditable analytics foundation. Weekly dashboard replaced ad-hoc screenshot reporting. Parameter coverage lifted from ~15% to ~98%; modelled data gaps cut from ~35% to ~8%. Full measurement spec delivered for future analyst handoff.
